GeoServer GeoFence WPS Extension
--------------------------------

This package contains GeoFence's authorization hooks for WPS process execution (chained process
tracking), distributed as a separate plug-in.

Please report any bugs with jira (https://osgeo-org.atlassian.net/projects/GEOS).

Any other issues can be discussed on the mailing list (http://lists.sourceforge.net/lists/listinfo/geoserver-users).

Requires the `geofence` (or `geofence-server`) and `wps` plugins to already be installed.

Installation
------------

1. Copy the included jar files into the WEB-INF/lib directory of your GeoServer installation.

2. Restart GeoServer.
